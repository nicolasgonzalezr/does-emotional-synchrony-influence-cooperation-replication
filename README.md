# Does emotional synchrony influence cooperation? Dynamic evidence from facial expressions in negotiations

Replication package for **“Does emotional synchrony influence cooperation? Dynamic evidence from facial expressions in negotiations”**

**Work in progress:** This project is ongoing. The analyses and replication materials are not yet finalized and may change.

## Replication materials

The replication package is being prepared. Analysis code, supporting files, software requirements, and instructions for reproducing the results will be added as they become available. Preliminary scripts may be inspected but data will not be made available until manuscript submission.
